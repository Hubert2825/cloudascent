☁️ Cloud Ascent

AWS Certified Cloud Practitioner Study Climb
How to play:
1. Answer AWS Cloud Practitioner questions to climb the ladder, one rung per question.
2. Every question has four choices and one correct answer. Choices are shuffled each time you play.
3. Each wrong answer costs one life (☁️). You always see the correct answer and a short explanation before moving on.
4. Reach the top before your lives run out to earn the Cloud Practitioner badge. Lives are set so that finishing means you scored at least 70%, the same bar as the real exam.
5. Out of lives? It's game over, but you can climb again with a fresh shuffle.
